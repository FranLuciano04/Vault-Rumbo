# Justificación del sistema

tags:: #tipo/referencia #estado/formalizado #pc/pc1

Por qué vale la pena construir Rumbo: el trabajo manual de la agencia genera problemas concretos que un sistema a medida resuelve mejor que Excel o un CRM genérico.

## Un problema real y costoso
Gestionar en papel y Excel hace que se pierdan ventas, se olviden cobros y no quede memoria del cliente.

## El activo son los clientes fieles
Con pocos clientes nuevos, retener y volver a venderles sostiene el negocio: el sistema aprovecha el historial y las preferencias de cada [[Cliente]].

## Las herramientas genéricas no alcanzan
Ni Excel ni un CRM genérico entienden las reservas, las comisiones, las cuotas y los vencimientos propios del turismo.

## Impacto esperado
Menos tiempo administrativo, menos vencimientos perdidos y más consultas que terminan en venta.

## Como proyecto integrador
Combina web, mobile, backend, base de datos relacional, API REST e IA sobre una problemática concreta y verificable.
