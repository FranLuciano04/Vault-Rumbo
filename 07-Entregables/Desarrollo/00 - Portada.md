# Presentación

Este documento describe el **modelo de desarrollo** que sigue el equipo para construir **Rumbo**, entendido como su metodología de trabajo: el ciclo de vida del proyecto, las prácticas con las que tres personas trabajan sobre una misma base, cómo se controla la calidad del código y cómo se diseñaron las interfaces.

Cierra con las **interfaces gráficas** del prototipo navegable: cada pantalla se presenta con el caso de uso que realiza, cuya especificación está en el documento de casos de uso.
