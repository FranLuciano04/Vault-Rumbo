
# Material complementario: carpeta de entrega

Junto con este documento se entrega una carpeta con todo el material del Punto de Control 1, ordenada así:

| Carpeta | Contenido |
|---|---|
| **01 · Documento principal** | Este documento, en Word y en PDF. |
| **02 · Presentación** | La presentación de la exposición oral. |
| **03 · Anexos** | Relevamiento y definición del proyecto; especificación de requisitos (155 funcionales y 16 no funcionales, con la matriz de trazabilidad); especificación de los 31 casos de uso; inteligencia artificial; modelo de desarrollo con todas las interfaces gráficas. |
| **04 · Diagramas** | Todos los diagramas en imagen, en una subcarpeta por tipo: casos de uso, clases, entidad-relación, estados, actividad, secuencia, arquitectura y C4. |
| **05 · Prototipo** | Las pantallas del prototipo navegable y el enlace al archivo de Figma. |
| **06 · API** | El contrato OpenAPI completo, `openapi.json`. |
| **07 · Base de datos** | El script SQL completo, `rumbo.sql`. |
| **08 · Agentes** | `CLAUDE.md`, las instrucciones del agente de desarrollo. |
