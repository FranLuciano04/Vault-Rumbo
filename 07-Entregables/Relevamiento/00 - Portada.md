# Presentación

**Rumbo** es un CRM a medida para agencias de turismo PyME. Este documento reúne el **relevamiento** realizado sobre una agencia real y la **definición del proyecto**: cómo trabaja hoy la agencia y qué ofrece el mercado, por qué el sistema vale la pena, qué objetivos persigue, hasta dónde llega su alcance, quiénes lo usan y cómo es el circuito de trabajo que digitaliza.

Es el punto de partida del trabajo: sobre este relevamiento se elaboró la **especificación de requisitos** y, a partir de ella, la **especificación de casos de uso**, que se entregan como documentos separados.
