# Vault-Rumbo

Memoria compartida y **sistema único de verdad** del proyecto **Rumbo** — CRM para agencias de turismo PyME.
Trabajo de Campo 2026 · Universidad de Morón · Equipo: Paloma Patiño, Nahuel Viniegra, Francisco Luciano.

## Cómo empezar
1. Abrir esta carpeta como **vault** en Obsidian.
2. Ir a `00-Inicio/🏠 Rumbo — Home.md`.
3. Leer una vez `00-Inicio/Guía del Vault.md` (cómo trabajamos).

## Plugins recomendados
- **Obsidian Git** — sincronización y versionado (obligatorio).
- **Templater** o Core Templates — plantillas de `_plantillas/`.
- **Dataview** — consultas de estado en los MOC.

## Sincronización
El vault es un repositorio Git. `pull` al abrir, commit frecuente, push al terminar.
Ver `00-Inicio/Guía del Vault.md → §3` y `_meta/`.
